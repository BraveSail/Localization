# Localization packs (Mizugram fork)

This repository is a fork of [TDesktop-x64/Localization][upstream] and serves
the same `*.json` language packs that the Mizugram build downloads.

**All translation content in this repository is the work of the 64Gram
(TDesktop-x64) authors and their translators.** This fork only re-hosts the
files; the language packs themselves are not maintained here.

[upstream]: https://github.com/TDesktop-x64/Localization
